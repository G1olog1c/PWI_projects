# UX Analysis — Revline Magazine

## 1. Problem / User Need

Car enthusiasts lack a dedicated online space that combines
editorial quality with authentic automotive culture.
Existing platforms are either too commercial or too generic.
Revline addresses the need for a focused, visually immersive
magazine experience built specifically for people who are
passionate about cars.

## 2. Target Audience

- Age: 18–35
- Gender: predominantly male, but not exclusively
- Interests: JDM culture, classic American muscle, motorsport,
  car meets, builds and modifications
- Behavior: browses on both desktop and mobile,
  values aesthetics and authenticity over corporate tone

## 3. Page Structure Justification

- **Hero** — immediate visual impact; establishes the brand
  tone before the user reads a single word
- **About** — answers "what is this?" for first-time visitors;
  builds trust and context
- **Featured Cars** — core content; three-column grid allows
  quick scanning and comparison
- **Contact** — low-friction entry point for community
  submissions; prepares for future backend integration

The one-page structure was chosen intentionally —
car enthusiasts browse impulsively and value speed.
A single scrollable page reduces friction and keeps
the user engaged without navigation overhead.

## 4. Color & Layout Choices

- **Dark background (#0a0a0a)** — reflects the atmosphere
  of a nighttime car meet; reduces eye strain during
  late-night browsing sessions
- **Red accent (#e63329)** — universally associated with
  speed, urgency, and passion; used sparingly to draw
  attention to key actions
- **Bebas Neue font** — bold, condensed, aggressive;
  matches the personality of performance car culture
- **Inter font** — clean and highly readable for body text;
  contrasts well with the display heading font
- **Three-column grid** — mirrors the layout of editorial
  print magazines; creates visual rhythm and allows
  content comparison at a glance
